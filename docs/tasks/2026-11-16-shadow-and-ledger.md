# 手燭と女将の影／自分の記録が残る宿帳

仕様の正本は `docs/GDD.md` の 2章（手燭と女将の影）と 3章（宿帳）。迷ったら GDD を読む。番号（2.8 など）は GDD の節。

## 目的（プレイヤー体験として何が良くなるか）
- 自分の手燭が女将を呼ぶ。「点ければ見えるが、見られる」を自分の指で選び続ける駆け引きが、ほかの和風ホラーにないこのゲームの手触りになる
- 女将は最後まで姿を見せず、自分の灯りが落とす「そこにいない誰かの影」だけで迫ってくる
- 宿帳に自分の周回（日付・名前・泊まった長さ・結末）が残り、「この宿に覚えられている」怖さが生まれる

## 仕様
GDD 2.3〜2.13、3.2〜3.7。要点だけ:
- F／スマホの「火」ボタンで手燭の火を吹き消す・点ける。蝋は減らない
- 暗がりで火を点けていると「気配」が溜まり、段階1（足音・炎が傾く・離れた壁に影）→ 段階2（衣擦れ・見ていないと近づく）→ 100 で見つかる
- 見つかると振り向かされて壁いっぱいの影 → 火を吹き消される → 最後の明るい場所に戻る。持ち物は失わない
- 火が点いているあいだは手燭が shadowLight を受け持つ。実光源の数は増やさない
- 湯の底の札は火を消すと見える。二周目は手紙を持って火を掲げ、女将に見つけてもらうとエンディングC
- 宿帳は保存した記録から作る。記帳した名前は次の周の「今宵」に薄く出て「名前をなぞる」になる。設定で記録を消せる
