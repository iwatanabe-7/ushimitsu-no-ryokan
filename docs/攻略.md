# 丑三つの旅館 攻略

> 物語と謎の答えをすべて書いています。自分で解きたい人は、詰まったところだけ読んでください。

## 基本

| 操作 | キー |
|---|---|
| 移動 | W / A / S / D（Shift で少し速く） |
| 視点 | マウス |
| 調べる・文章を送る | E |
| 花札錠：札入れを選ぶ / 札を替える / 試す | ← → / ↑ ↓ / Enter |
| 一時停止・設定 | Esc |

- 画面の中央の点が大きくなり「E 調べる」と出たものが調べられます。
- 時計は午前2時から進み、2時30分で止まります。**時間切れはありません。**
- 手に入れた物は画面右下に並びます。

## 宿の間取り

- **一階**：廊下の北に 椿の間（西）・菖蒲の間・桔梗の間（東）、南に 帳場 と 玄関
- **東の棟**：渡り廊下の北に中庭、南に大広間、突き当たりに脱衣所と露天風呂
- **二階**：廊下の西の階段から。松の間と竹の間

- 廊下の西の突き当たりに階段、東の突き当たりは渡り廊下です。
- 渡り廊下の北が中庭（高欄の切れ目から下りられる）、南が大広間、突き当たりが湯殿の板戸です。

## 一周目の流れ（エンディングA）

### 1. 椿の間（自分の部屋）

1. 目を覚ますと午前2時。枕元の時計を調べてもよいですが、必須ではありません。
2. **押入れ**を調べて開け、中段の**浴衣**を調べる → **「廊下の鍵」**
3. **床の間**に置かれた花札を調べる → **「椿の札」**
   - これを取るまでは、襖を開けても廊下に出られません。
4. 南の**襖**を調べ、廊下の鍵で開けて廊下へ。

### 2. 帳場（廊下の向かい、暖簾のある所）

- **宿帳**を調べると、泊まった客の記録が右から古い順に並んでいます。
- 名前の横に**花の印**がついているのは、次の3人だけです。この並びが最後の錠の答えになります。

  | 古い順 | 部屋 | 印 | 名前 |
  |---|---|---|---|
  | 1 | 桔梗の間 | 桔 | 千代 |
  | 2 | 菖蒲の間 | 菖 | 遠野 誠一 |
  | 3 | 椿の間 | 椿 | （空欄＝あなた） |

- **「記帳する」は押さないこと。** 名前を書くとエンディングB（宿に残る）になります。「閉じる」で戻ります。

### 3. 菖蒲の間（廊下の北、真ん中）

1. 襖に鍵はかかっていません。調べると開きます。
2. 文机の**日記の切れ端**に、桔梗の間の開け方と花の印の意味が書かれています。
3. **鏡台**を調べる → 鏡に女将の影が一瞬映ります（驚かせどころ）。
4. 引き出しの紙片に**「菖蒲の札は湯に浸けた」「湯殿の鍵は大広間の上座の膳」**と書かれています。

### 4. 大広間（渡り廊下の南）

1. 渡り廊下の南側の**襖**を調べて開けます。
2. 奥の舞台の手前、真ん中に一つだけ置かれた**上座の膳**を調べる → **「湯殿の鍵」**
   - 取ると、誰もいない舞台で手を打つ音がします。

### 5. 大浴場（渡り廊下の突き当たり）

1. 突き当たりの**板戸**を調べ、湯殿の鍵で開けます。
2. 脱衣所の北の「ゆ」の暖簾をくぐると露天風呂です。
3. **岩風呂の西側（脱衣所寄り）の湯の底**を調べる → **「菖蒲の札」**
   - 縁から手を伸ばしても、湯船に入ってからでも拾えます。

### 6. 桔梗の間（廊下の北、東の端）

1. 襖の右にある**札入れ**を調べると、椿の札と菖蒲の札をはめて開けられます。
   - 2枚そろっていないと開きません。
2. 奥の**文机**を調べる → **「桔梗の札」**
   - 取ると、廊下の提灯がすべて消え、外を足音が通り過ぎます（驚かせどころ）。帳場と玄関の明かりを頼りに進みます。

### 7. 玄関（廊下の南、東寄り）

1. 土間に下り、引き戸の右の**花札錠**を調べます。
2. 宿帳の花の印の古い順に、左から札をはめます。

   **左：桔梗　→　中：菖蒲　→　右：椿**

   - ← → で札入れを選び、↑ ↓ で札を替え、Enter で試します。
   - 間違えると札が戻り、柱時計が一度鳴るだけです（何度でもやり直せます）。
3. 正解すると、背後の壁に女将の影が伸び、「お帰りですか」と聞こえます（驚かせどころ）。
4. **エンディングA「脱出」**

## エンディング一覧

| | 名前 | 条件 |
|---|---|---|
| A | 脱出 | 花札錠を開けて玄関から出る |
| B | 宿に残る | 帳場の宿帳で「記帳する」を選び、名前を書く |
| C | 真相 | 二周目で「娘の手紙」を女将の影に渡す |

見たエンディングはタイトル画面と終幕の画面に表示されます。

## 二周目（エンディングC）

エンディングAを一度見ると、次からは二周目になります（タイトル画面に「二周目」と出ます）。宿の様子が少し変わります。

- 宿帳に、一周目の自分の記録（椿の間、日付なし）が増えています。
- 菖蒲の間の日記に、娘が秋に亡くなったことを書いたページが増えています。
- 桔梗の間の文机の引き出しに**「娘の手紙」**が現れます。

手順：

1. 一周目と同じ流れで、桔梗の間まで進みます。
2. 文机を調べて桔梗の札を取ったあと、**もう一度文机を調べる** → **「娘の手紙」**
3. 廊下に戻ると、消えていた提灯が一つだけ灯り、帳場と玄関のあいだの壁に**女将の影だけ**が映っています（影の主はいません）。
4. 影の前で調べて、手紙を渡す → **エンディングC「真相」**

## 寄り道（クリアには不要）

| 場所 | 見どころ |
|---|---|
| 中庭 | 月が映る池、火の入った石灯籠、松の幹の背比べの傷、古井戸 |
| 大広間 | 並んだ膳、金屏風の端の小さな赤い手形 |
| 二階・松の間 | 佐伯の書き置き。花の印は「残る客」につける印だと分かる |
| 二階・竹の間 | 小松の書き置きと、「ちよ」と書かれた折り鶴。入ると廊下を小さな足音が走り抜ける |
| 桔梗の間 | 衣桁の着物、手鞠、目を離すとこちらを向いている市松人形 |

## 困ったとき

- **廊下に出られない**：床の間の椿の札を取っていません。
- **桔梗の間が開かない**：椿の札と菖蒲の札の2枚が必要です。菖蒲の札は露天風呂の湯の底です。
- **湯殿の板戸が開かない**：大広間の上座の膳にある「湯殿の鍵」が必要です。
- **花札錠が開かない**：左から 桔梗・菖蒲・椿 です。
- **暗くて見えない**：花札は暗がりでもほんのり光っています。重いときや見づらいときは、Esc の設定で画質を変えられます。
