## 1. ゲーム全体の要約（今の状態）

### 1.1 一言で
山あいの古い旅館に泊まった客が、午前2時に目を覚まして宿から出ようとする一人称3D脱出ホラー。丑三つシリーズ第2作。
**女将は一度も姿を見せない。** 画面に映らない人形を灯りの前に立たせ、壁や鏡に落ちる影だけで女将を表す。これがこのゲームのいちばんの持ち味。

### 1.2 技術の前提
- Three.js ＋ Vite。Web 版（GitHub Pages）と Electron 版を出す。スマホのブラウザでも遊べる
- テクスチャも音もコードで生成（画像・音声ファイルなし）
- 文章は `src/game/messages.js`、保存は `src/game/save.js`（localStorage）
- 自動プレイ: `harness/playthrough.mjs`（エンディングAまで）、`harness/regressions.mjs`（不具合の再発確認）、`harness/shots.mjs`（撮影）

### 1.3 操作（今）
| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD（Shift で少し速く。歩き 1.7 / 速歩き 2.3 m/秒） | 画面左半分をドラッグ |
| 視点 | マウス | 画面右半分をドラッグ |
| 調べる・文章を送る | E / Space / Enter | 「調べる」ボタン |
| 花札錠 | ← → ↑ ↓ Enter | 札入れを押す |
| 一時停止・設定 | Esc | （未対応。残作業） |

### 1.4 灯りと影の仕組み（新機能の土台）
- 灯りは `ctx.lamps` に多数（行灯・提灯・燭台など約25個）。`ctx.addLamp()` で登録し、`level`（0〜）で明るさを変える
- 区画（zone）がつながっているあいだだけ互いの灯りが見える（閉じた部屋の光は漏れない）
- 実際の光源は2種類
  - **shadowLight**（点光源・1個・影を落とす）: いちばん近い灯りに置く。影の描き直しは灯りが替わったとき・建具が動いているとき・女将の人形が出ているときだけ（6方向の影を描くのが一番重い）
  - **pool**（点光源・影なし）: 残りの灯りを「明るさ÷距離²」の大きい順に割り当てる。使う数は画質で 高6・中4・低3
- 女将の人形（`buildOkami({mode:'caster'})`）は色も奥行きも書かない材質で、影の計算にだけ加わる。使わないときは床下（y=-50）に置いて描画から外す
- 演出中だけ影の灯りを指定する `forcedLamp` がある

### 1.5 宿の間取り
- 一階: 廊下の北に椿の間（自室）・菖蒲の間・桔梗の間、南に帳場・玄関。廊下の西端に階段、東端は渡り廊下
- 東の棟: 渡り廊下の北に月明かりの中庭、南に大広間、突き当たりに脱衣所と露天の岩風呂
- 二階: 松の間（佐伯）・竹の間（小松）。寄り道

### 1.6 一周目の流れ
1. 椿の間: 押入れの浴衣から「廊下の鍵」、床の間から「椿の札」
2. 帳場: 札掛け（花札錠の答え。毎回ランダム）、宿帳（記帳するとエンディングB）
3. 菖蒲の間: 日記。鏡台で **驚かせ1**（鏡に黒い人影）。紙片で湯殿の鍵と菖蒲の札の場所が分かる
4. 大広間: 上座の膳から「湯殿の鍵」。誰もいない舞台で手を打つ音
5. 大浴場: 露天の湯の底から「菖蒲の札」
6. 桔梗の間: 椿と菖蒲の札で開く。「桔梗の札」を取ると **驚かせ2**（廊下の提灯が全部消え、足音が菖蒲の間の前で止まる）
7. 玄関: 花札錠。間違えるたびに提灯が細り足音が近づく。正解で **驚かせ3**（背後の壁に女将の影、「お帰りですか」）→ エンディングA

### 1.7 二周目とエンディング
| | 名前 | 条件 |
|---|---|---|
| A | 脱出 | 花札錠を開けて玄関から出る（これを見ると次から二周目） |
| B | 宿に残る | 宿帳で「記帳する」→ 名前を書く |
| C | 真相 | 二周目、桔梗の間の「娘の手紙」を女将の影に渡す |

二周目の差分: 宿帳に「日付なし・椿の間」の自分の行が増える、日記にページが増える、手紙が現れる。手紙を取ると宿じゅうの灯りが消えて提灯が一つだけ灯り、帳場の前の壁に女将の影だけが立つ。

### 1.8 保存（今）
`ushimitsu-no-yado/v1` に `clearCount`（Aを見た回数）、`seen`（A/B/C）、`best`（結末ごとの最短秒）、`settings`（音量・視点の速さ・画質・自動調整）。

## 2. 新機能1：手燭と女将の影（主役）

> **2026-11-17 の変更（ユーザーが遊んだうえでの判断）**: 途中で女将の影が壁際に立つこと（2.8 の段階1・2の影）と、気配 100 で見つかって明るい場所へ戻されること（2.9）は**使わない**。気配は、炎の傾き（影がないので背後へ引かれるように傾く）・足音・衣擦れと息・画面のふちの暗さの手がかりとしてだけ残る。`balance.js` の `OkamiShadowEnabled` / `CatchEnabled` を true にすると元の駆け引きに戻る。驚かせ3（玄関）の影はそのまま。
> **手燭は最初から持たない**（2.11 の目覚めの「枕元の手燭に…」はやめる）。帳場の机の上、女将の宿帳の横に客用の手燭が置いてあり、調べると行灯の火を移して手に入れる。手に入れるまでは暗がりで火がなく、手探りになる。
> **点け消しの動作**：吹き消すときは手燭を口元へ持ち上げ、息で炎が奥へ倒れて消え、細い煙を残して手元へ戻す（約0.8秒）。点けるときは左手の燐寸を芯へ寄せて擦り、火を移して燐寸を下げる（約1.35秒、点くのは1.0秒）。動作の途中は F を受け付けない（点ける途中は押すとやめる）。
> **二周目、娘の手紙を読み終えると**、宿じゅうの灯り（蝋燭・行灯・提灯）と手燭の火が消え、手燭は**二度と点かない**（F を押すと「燐寸を擦っても、火はすぐに消えてしまう。」）。そのあと一つだけ灯る提灯は、廊下にもともと吊ってある x=6.6 のものをその場で灯す（以前は宙に浮いた低い位置へ動かしていて不自然だった）。M3（手紙を持って火を掲げ、女将に見つけてもらう）は、この変更と合わないので作り直しが要る。
> **女将の声（読み上げ）は使わない**（2026-11-19）。驚かせ3の最後に手燭を吹き消す動作もやめる（細った火のまま暗転）。台詞は字幕だけで出す。
> あわせて、壁に近づくと手燭がまぶしすぎて目が痛いという指摘から、壁までの距離が 1.2m より近いと手燭を (距離 ÷ 1.2)² 倍に弱める（`CandleNearFull` / `CandleNearMin`）。

### 2.1 目的（プレイヤー体験）
- 和風ホラーの多くは「追いかけてくる化け物から隠れる」。このゲームでは**自分の持つ灯りが、女将を呼ぶ**。
- 火を点ければ見える。しかし灯りのあるところにしか女将は現れられない。火を吹き消せば女将は消えるが、自分も見えなくなる。
- 「明るくすると見えるが、見られる」。火を点けるか消すかを、プレイヤーが自分の指で何度も選ぶ。それがこのゲームの手触りになる。
- 女将の姿は最後まで出さない。プレイヤーが見るのは、**自分の灯りが壁に落とす、そこにいない誰かの影**だけ。

### 2.2 絶対に守ること
1. 女将の姿（色のある形）は画面に一切出さない。使うのは `caster` の人形が落とす影だけ（鏡の驚かせ1の黒い人影は今のまま例外として残す）
2. 見つかってもゲームオーバーにしない。少し前の明るい場所に戻すだけで、持ち物も謎の進み具合も失わない
3. 時間切れで詰まない。蝋は減らない（2.5 参照）
4. 影を落とす灯りは1つのまま。実光源の数（高6・中4・低3）も増やさない
5. スマホで同じように遊べる

### 2.3 遊びの流れ（1回の駆け引き）
```
暗がりに入る ──→ 手燭の火で足元と壁が見える
   │                    │ 灯りを持っているあいだ「気配」が溜まる
   │                    ↓
   │        ［気配1］遠くで足袋の音。手燭の炎がどこかへ引かれて傾く
   │                    ↓  音の方を向くと、数歩先の壁に誰かの影
   │        ［気配2］すぐ近くで衣擦れと息。炎が大きく傾き、明かりが乱れる
   │                    ↓  見ていないうちに、影の主は近づいてくる
   │        ［見つかる］振り向かされ、壁いっぱいの影 → 火を吹き消される → 少し前の灯りの下に戻る
   │
   └─ 途中で火を吹き消す（F／「火」）→ 影は消え、気配は引いていく。
        ただし真っ暗で、目が慣れるまでほとんど見えず、手探りでゆっくりしか歩けない。
        点け直すには1秒ほどかかる
```

### 2.4 手燭の操作
| 操作 | PC | スマホ |
|---|---|---|
| 火を吹き消す／点ける（切り替え） | **F** | 「調べる」の左に **「火」ボタン**（指で押しやすい 64px 以上） |

- 手燭は**最初から持っている**。目覚めの場面のあと、右手の下に真鍮の手燭（皿・持ち手・短い蝋燭・炎）が見える。最初は火が点いている
- **吹き消す**: 押すとすぐ「ふっ」と息の音（`audio.snuff`）、0.25秒で炎が細って消える。消している最中に移動してよい
- **点ける**: 押すと付け木を擦る音がして、1.1秒後に火が点く。点けているあいだも歩ける（速さは手探りのまま）。途中でもう一度押すとやめる
- 文章が出ているあいだ・宿帳や花札錠の画面・一時停止中は切り替えられない（押しても何も起きない）
- 演出の場面（`state.phase === 'scene'`）では切り替えられない

### 2.5 資源にするか → **しない（蝋は減らない）**
- 判断: 火を点けているあいだは「気配」が溜まるので、点けっぱなしにはできない。これがすでに時間の圧力になっている。蝋の残りまで足すと圧力が二重になり、何を気にすればいいか分かりにくい。燃え尽きは「時間切れで詰まない」とも相性が悪い
- 代わりに「消している時間」に代償を払わせる: 暗くて見えない・遅い・点け直しに時間がかかる
- 遊んでみて「点けっぱなしで平気」「消すことに迷いがない」と感じたら、代案（6.2）の蝋を検討する

### 2.6 暗がり
- **暗がり**＝自分の位置で、手燭以外の灯りの強さ `max(L.now ÷ max(1, 距離²))` が `DarkThreshold` 未満の場所。毎フレーム、すでに pool の割り当てで計算している値を使う
- 出入りの判定は `DarkEnterDelay` 秒続いたときに切り替える（境目でちらつかない）
- 月明かり（`moon`）は灯りに数えない。月の下は「暗がりだが、火がなくても歩ける」場所になる
- 暗がりの場所（どこが暗いかは遊んで調整する。最初は下の表から始める）

| 場所 | 一周目の始め | 驚かせ2のあと | 二周目で手紙を取ったあと | 性格 |
|---|---|---|---|---|
| 椿・菖蒲・桔梗の間、帳場、玄関、大広間 | 明るい | 明るい（玄関は錠を間違えると暗くなりうる） | 暗い | 灯りの下。気配は溜まらず、引いていく |
| 一階の廊下 | 明るい | **暗い（屋内・火がないと見えない）** | 暗い | 驚かせ2のあとの最後の山場 |
| 渡り廊下・中庭 | **提灯を消しておく（月明かり）**。石灯籠のまわりだけ明るい | 同じ | 暗い | 月の下。火を消しても歩ける「息つぎの暗がり」 |
| 脱衣所 | **行灯を消しておく** | 同じ | 暗い | 屋内の暗がり。狭い |
| 露天風呂 | **提灯を消しておく（月明かり）** | 同じ | 暗い | 湯の底の謎（2.10） |
| 階段・二階 | **提灯・行灯を消しておく** | 同じ | 暗い | 寄り道。佐伯・小松の書き置きを火で読む |

### 2.7 火を点けているとき／消しているとき
| | 火を点けている | 火を消している（暗がり） |
|---|---|---|
| 見えるもの | 手燭のまわり約5m。柱や格子の影が手の動きで揺れる | 最初の 0.15 倍の明るさから、2.5秒かけて 0.45 倍まで「目が慣れる」。遠くの灯り・月明かり・花札のほのかな光・**湯の底の光（2.10）** |
| 調べる | すべて今どおり | 読む物（日記・書き置き・札掛け・宿帳・掛け軸・手紙）は「暗くて、字が読めない。」。花札・鍵・戸・襖は手探りで調べられる |
| 歩く速さ | 今どおり | 0.65 倍（手探り） |
| 女将 | 気配が溜まり、影が現れる | 現れない。気配は 1.5秒おいてから引いていく |
| 影の灯り（shadowLight） | **手燭が受け持つ** | 今どおり、いちばん近い灯り |

- 明るい場所（暗がりでない所）で火を点けていても気配は溜まらない。手燭は shadowLight のまま（部屋の柱の影が手燭から落ちる）
- 画面のふち（ビネット）を気配に合わせて少しだけ暗くする（最大 0.35）。数値のメーターは出さない。ホラーの画面に数字は要らない。手がかりは炎・音・ふちの暗さの3つ

### 2.8 気配（女将がこちらに気づいている度合い）
- 0〜100 の隠れた値。`src/game/kehai.js` の純粋な関数で計算する（テストできる形）
- 溜まる条件: **暗がりで・火が点いていて・女将が歩いている（`state.okamiAwake`）** とき
  - 歩いている: 6.0／秒（約17秒で見つかる） 立ち止まっている: 3.5／秒（約29秒）
  - 文章を読んでいるあいだも 4.0／秒で溜まる（火で日記を読むのは危ない）。ただし文章のあいだは 90 で止め、閉じたあと 1.0秒は見つからない
- 引く条件: 火を消している、または明るい場所にいる。最後に溜まってから 1.5秒おいて 12／秒で引く
- 段階（下がるときは 8 だけ手前で戻る。境目でちらつかない）

| 段階 | 気配 | 女将の影 | 音 | 手燭 |
|---|---|---|---|---|
| 0 静か | 0〜34 | 出ない | なし | 普通に揺れる |
| 1 気づき | 35〜69 | 手燭から 3.0m の、**今見ていない方向**に立つ。音の方を向くと壁に影が見える | その位置で足袋の足音を1回（`audio.stepWood`、小さめ） | 炎が女将の方へ 0.15rad 傾く |
| 2 接近 | 70〜99 | 1.8m まで来る。**見ていないあいだだけ** 0.3m/秒で近づく（最短 1.0m）。2秒以上見ていなければ、背後側へ回り込める | 衣擦れと息（`audio.breath`） | 炎が 0.45rad 傾き、明るさが ±25% 乱れる |
| 3 見つかる | 100 | 2.9 の演出 | | |

- 「見ているあいだは近づかない」は、桔梗の間の市松人形（見ていないうちにこちらを向く）と同じ文法。プレイヤーは影を見つめたまま後ずさりできるが、気配は溜まり続けるので、最後は火を消すしかない
- 女将の立つ位置の決め方（段階が上がったとき・回り込むとき）
  1. 手燭から決まった距離の円周上を8方向調べる
  2. 歩ける床の上（`ctx.walk`、`player.floorAt`）で、壁にめり込まない
  3. 手燭からその位置まで壁にさえぎられない（レイを壁に当てる）
  4. その先 4m 以内に影が落ちる面（壁・床・襖）がある
  5. 段階1・回り込みは視野の外、段階2の接近中は今いる位置からまっすぐ寄る
  6. 候補がなければ、その段階では影を出さない（音と炎だけ）
- 火を吹き消したら 0.3秒後に女将を床下へ戻す（光がないので影はもともと見えない）
- 二周目は気配の溜まり方が 1.25 倍（宿があなたを覚えている）
- 見つかった回数に応じて、溜まり方を 0.8 倍ずつ下げる（下限 0.6 倍。プレイヤーには言わない、やさしさの補正）

### 2.9 見つかったとき（ゲームオーバーにしない）
1. 操作を止める（`state.phase = 'scene'`、映画の帯）
2. 0.8秒で背後の女将の方へ振り向かされる（`turnAnim` を使う）。女将は手燭から 0.9m に立っているので、**その向こうの壁いっぱいに影**が映る。影の主はいない
3. 1.2秒そのまま。息の音。声「夜道は、危のうございます」（`audio.voice` と字幕）
4. 手燭の火が吹き消され（炎が女将の方へ倒れて消える）、1.0秒で暗転
5. **最後にいた「明るい場所」**（暗がりでない所に 1.0秒以上いた最後の位置と向き）に立って、明けていく。手燭には火が点いている。気配は 0
6. 字幕「……気がつくと、灯りの下に立っていた。」。**初めて見つかったときだけ**、続けて「灯りを持ったまま暗がりにいると、見つかる。（F／「火」で吹き消す）」
- 2回目以降は演出の長さを 0.6 倍にする（繰り返しで退屈しない）
- 持ち物・開けた戸・謎の進み具合・時計はそのまま。失うのは「歩いた距離」だけ
- `state.caught` に回数を数える（宿帳の記録にも残す。表示はしない）
- 花札錠・宿帳の画面が開いているあいだ、文章が出ているあいだは見つからない（気配は 90 で止まる）

### 2.10 追加の謎：湯の底の札（火を消して見る）
「消したときにしか見えないものがある」ことを、必ず通る場所で一度だけ教える。
- 菖蒲の札は露天の湯の底にある（今と同じ。菖蒲の間の紙片で場所は分かっている）
- **火を点けて**岩風呂の西側（今の当たり判定）を調べる: 「湯面に手燭の火が映って、底が見えない。」。2回目以降: 「湯面に、自分の手燭が揺れている。……火がなければ、底が見えるだろうか。」
- **火を消す**と、月明かりの下で湯の底に札がほのかに光る（札の発光を暗がり・火なしのときだけ上げる）。その状態で調べると今の `bathCard` の文章で手に入る（1行目を「暗い湯の底で、何かが淡く光っている。」に差し替え）
- 露天は月明かりなので、火を消してもまわりは見える。「消すと怖い」ではなく「消すと見える」を気持ちよく体験させる場所
- 露天でも火を点けていれば気配は溜まる。湯面を何度も調べていると女将が来る

### 2.12 二周目のエンディングC（駆け引きを裏返す）
一周目からずっと女将の目を逃れて火を消してきたプレイヤーに、**最後だけは火を掲げて、女将に見つけてもらう**。
1. 手紙を取ると、今と同じく宿じゅうの灯りが消える（提灯を一つ灯すのはやめる）。字幕「……宿じゅうの灯りが消えた。手燭の火だけが残っている。」
2. ここからは宿全体が暗がり。気配の溜まり方は普段と同じ
3. 手紙を持って段階1になったとき、字幕「今度は、火を消さなくていい気がした。」
4. **手紙を持っているときは「見つかる」が起きない**。気配 100 になると、女将は手燭から 1.3m の、**プレイヤーが向いている方向**に立つ。音が止み、炎がまっすぐ立つ（傾かない）。字幕「灯りの向こうに、誰か立っている。」
5. その位置に当たり判定（今の `okamiHit`）を置き、「女将の影」を調べられる。調べると今の `okamiShadow` → `okamiGive` → エンディングC
6. 火を消すと、女将はその場に留まる（影は見えなくなるが、点け直すとまだそこにいる）
- 今の「帳場の前の決まった場所に影が立つ」（`OKAMI_SPOT`）の仕組みは、遊んで手触りが悪かったときの代案として残す

### 2.13 実装の仕組み（今のコードで実現する形）
- **手燭＝shadowLight**: 火が点いているあいだは、いちばん近い灯りの代わりに手燭の位置へ shadowLight を置く。押し出された灯りは pool（影なし）に回る。実光源の数は変わらない
  - 優先順位: `forcedLamp`（演出）＞ 二周目の演出 ＞ 手燭（点いているとき）＞ いちばん近い灯り
- 手燭の位置: カメラから 右 0.20・下 0.30・前 0.38 m。歩くと少し揺れる。手燭の見た目（皿・蝋燭・炎）はカメラの子にし、影は落とさない
- **影の描き直しの間引き**（重さ対策の中心）: 手燭は動くので、そのままでは毎フレーム6方向の影を描くことになる
  - 女将がいないとき: 手燭が 0.04m 以上動いたときだけ、最大 15回／秒
  - 女将がいるとき: 最大 30回／秒（画質「高」は毎フレーム）
  - 画質「低」で女将がいないときは、手燭は影を落とさない（柱の影を省く。女将の影だけは必ず出す）
  - 手燭の影カメラの遠さ（far）は手燭の届く距離に合わせる
- 暗がりの判定・気配・段階・見つかる判定は `src/game/kehai.js` に純粋な関数として切り出し、`node --test` でテストする（このプロジェクトにはまだテストの仕組みがないので足す）
- 数値は `src/game/balance.js`（設計書の GameBalance に相当）に集める。コードに数値を直書きしない
- 文章は `messages.js` に足す
- ハーネス用に `window.__game.candle`（`lit()`, `toggle()`, `kehai()`, `setKehai(v)`, `stage()`, `dark()`）を公開する
- 調整用に URL に `?debug=kehai` を付けると、画面の隅に 気配・段階・暗がり・火 を出す。`?dark=1` で最初から驚かせ2のあとの暗い廊下を再現する（マイルストーン1の確認用）

## 3. 新機能2：宿帳に自分の記録が残る（従）

### 3.1 目的（プレイヤー体験）
- 宿帳に、**自分が本当に遊んだ日付・名前・泊まった長さ・結末**が残っていく。周回するほど自分の行が増える
- 一度名前を書くと、次に来たとき「今宵」の欄にもう薄く名前が書いてある。「この宿に覚えられている」
- 保存画面を作らず、記録を物語の中の物（宿帳）に置く

### 3.2 保存する項目（`save.js` に足す）
```
ledger: [            // 古い順。上限 50 件（古いものから捨てる）
  {
    date: '2026-11-16',   // 遊び終えた日（端末の日付、YYYY-MM-DD）。移行した古い記録は null
    name: '渡辺',          // その周の名前。記帳していなければ ''（表示は「午前二時」）
    ending: 'A',          // 'A' | 'B' | 'C'
    sec: 1453,            // クリア時間（秒、整数）
    caught: 2,            // 見つかった回数（表示しない。調整用）
    released: false,      // エンディングCで「名前が消えた」記録
  }
],
guestName: '',       // 記帳した名前（8文字まで）。次の周の「今宵」に薄く出る
ledgerV: 1,          // 宿帳の記録の版
```
- 記録するのは**結末を見た周だけ**（`finish()` の中）。途中でタイトルに戻った周は残さない
- 読み込むときは中身を確かめる（配列でなければ空、文字列は長さを切る、`ending` は A/B/C だけ）
- **古い保存からの移行**: `ledgerV` がなく `clearCount >= 1` なら、今の「日付なし」の行の代わりに `{date:null, name:'', ending:'A', sec:0}` を1件だけ入れる。今の二周目の見え方がそのまま続く
- 名前は端末の中にだけ保存する（外へ送らない）

### 3.3 宿帳への表示
宿帳は縦書きで、右から古い順。今の4人の客の行のあとに自分の記録が続き、いちばん左が「今宵」。

**行の書式**（今の 日付・部屋・印・名前 の4つに「添え書き」を1つ足す）
| 欄 | 中身 |
|---|---|
| 日付 | 遊び終えた日を和暦の漢数字で。「令和八年 十一月十六日」。移行した記録は「日付なし」 |
| 部屋 | 「椿の間」 |
| 印 | エンディングBの周だけ椿の印（花の印は「残る客の印」なので物語と合う） |
| 名前 | その周の名前。記帳していない周は「午前二時」（宿があなたを呼ぶ名） |
| 添え書き（新） | 結末と泊まった長さを小さく。A「発つ　二十四分」、B「残る　十二分」、C「還る　四十一分」。分は四捨五入、1分未満は「すぐ」。移行した記録は添え書きなし |

- 自分の行は薄墨（今の `faded`）。いちばん新しい自分の行だけ少し濃くする
- 表示する自分の行は**新しい方から5行まで**。それより古いものがあれば、5行の右にもう1行「このほか　七泊」（日付・部屋は空、添え書きに件数）
- エンディングCで「消えた」記録（`released`）は、名前に二重線を引く
- その周で初めて宿帳を開いたとき自分の行があれば、閉じたあと字幕「……見覚えのある字がある。」

### 3.4 記帳（エンディングB）との関係
- `guestName` がないとき: 今どおり「記帳する」→ 名前を書く → エンディングB。書いた名前を `guestName` に保存する
- `guestName` があるとき:
  - 「今宵」の欄に**最初から薄く名前が書いてある**（新しい見た目 `ghost`：今の `faded` より薄い）
  - ボタンの文字が「記帳する」から **「名前をなぞる」** に変わる。押すと名前を聞かずに、その名前でエンディングB
  - 名前を変えたい人は、設定で宿帳の記録を消す（3.6）
- エンディングA・Cの周の記録の名前には `guestName`（なければ ''）を入れる
- エンディングBの終幕の宿帳（今の「次の客が宿帳を開いた」の場面）は今どおり。書いた行がそのまま次の周にも残る

### 3.5 二周目の「日付なしの自分の行」の整理
- 今の `ledgerEntries({ lap2, lap1Name })` の「日付なし・椿の間・午前二時」の行は**やめて**、保存した記録から作る
- 二周目かどうかの判定（`clearCount >= 1`）は今のまま。宿帳の行は周回数と関係なく記録から作る。だから、一周目にエンディングBを見た人は、次の一周目の宿帳に自分の名前（花の印つき）がもう載っている
- `ledgerEntries()` は `{ records, guestName, signed }` を受け取る純粋な関数にし、テストする

### 3.6 記録を消す
- 一時停止の画面（Esc）の設定の下に「記録」の欄を足す。ボタンは2つ
  - **「宿帳の記録を消す」**: `ledger` と `guestName` を消す。周回数・見た結末・最短記録・設定は残る
  - **「すべての記録を消す」**: 設定以外をすべて初めの状態に戻す（周回数も 0）
- どちらも確認を1回出す（「宿帳から、あなたの記録を消しますか。」［消す］［やめる］／「周回数と見た結末も含めて、すべて消しますか。」［消す］［やめる］）
- 消したあと字幕「宿帳の頁が、一枚破り取られた。」。開いている周の宿帳はすぐ変わる。「すべて」を消したときは、周回の差分が変わるので「タイトルへ戻ると反映されます」と添える
- 確認の画面では Enter で「消す」にならないようにする（今の「スライダーで Enter しても記帳しない」と同じ考え）

### 3.7 エンディングCとの関係

## 6. リスクと代案

### 6.1 重さ（いちばん大きいリスク）
- **リスク**: 手燭は動くので、点光源の6方向の影を何度も描き直す。スマホや内蔵GPUで重くなる
- **対策**: 2.13 の間引き（動いたときだけ・回数の上限・低画質は柱の影を省く・影カメラの far を短く）。自動の画質調整の測る場面に暗い廊下を入れる
- **代案A**: 画質「低」では手燭の影をスポットライト（前方 120°、影は1方向だけ）に替える。女将は見つかる演出以外では前方にしか立たせない
- **代案B**: 手燭自体は影を落とさず、女将が段階1以上のときだけ手燭に影を持たせる

### 6.2 点け消しの連打で何も怖くない
- **リスク**: 消してすぐ点ければ気配がたまらない、と分かると駆け引きがなくなる
- **対策**: 点け直しに 1.1秒、気配が引き始めるまで 1.5秒、目が慣れるまで 2.5秒。消す → 点けるの一往復に5秒ほどかかる
- **代案**: 蝋燭の残り（点けているあいだだけ減り、明るい部屋の行灯で替えられる。0 でも芯だけの小さな火で歩ける）。蝋を資源にするのは、遊んで足りないと分かってから

### 6.3 女将がどこにいるか分からない／影が見えない
- **リスク**: 立つ位置によって影が床や遠い壁に落ち、見えないまま見つかる
- **対策**: 立つ位置の条件に「その先 4m 以内に影の落ちる面」を入れる。炎の傾きと立体音で方向を必ず伝える。段階2の衣擦れは必ず鳴らす
- **代案**: 段階が上がるときは、廊下の壁など影がきれいに出る場所を区画ごとに数か所決めておき、そこから選ぶ（手で置く「影の出る所」）

### 6.4 見つかるのがつらい
- **リスク**: 同じ場所で何度も見つかって嫌になる
- **対策**: 戻るのは最後の明るい場所（遠くても十数m）。持ち物は失わない。見つかるたびに溜まり方が下がる（下限 0.6 倍）。2回目以降は演出が短い
- **代案**: 設定に「女将：ふつう／やさしい（気配の溜まり方 0.6 倍）」を足す

### 6.5 暗がりが少なすぎて主役にならない／多すぎて疲れる
- **リスク**: 2.6 の表では、必ず通る暗がりは東の棟と驚かせ2のあとの廊下だけ
- **対策**: マイルストーン1で手触りを確かめてから、暗くする場所を足す・減らす。暗がりは `level = 0` にするだけなので、場所の出し入れは安い
- **代案**: 大広間の行灯を始めは消しておき、上座の膳まで火を頼りに歩かせる（拍手の演出は燭台が一斉に灯る形に変える）

### 6.6 「女将は姿を見せない」が崩れる
- **リスク**: 近い距離で影を出すと、人形の一部がカメラの近くの面を切って映る、などの事故
- **対策**: 女将の人形は `caster`（色も奥行きも書かない）だけを使う。見つかる演出でも女将とカメラの間を 0.5m 以上あける。ハーネスで「女将の材質がすべて色を書かない」ことを確かめる

### 6.7 自動プレイが通らなくなる
- **リスク**: 気配で見つかったり、湯の底の札が取れなかったりして `playthrough` が止まる
- **対策**: `window.__game.candle` を公開し、`playthrough` は湯の底で火を消す。気配の検証は別の `candle.mjs` で行う

### 6.8 宿帳の記録
- **リスク**: 行が増えて宿帳がスマホの幅からはみ出す → 自分の行は5行まで＋「このほか」
- **リスク**: 端末の日付がずれている → そのまま出す（宿の帳面らしさとして許す）
- **リスク**: 他人に見られたくない名前 → 記録を消すボタン。名前は端末の外へ出さない（Steam のクラウドセーブをつなぐときは改めて決める）
